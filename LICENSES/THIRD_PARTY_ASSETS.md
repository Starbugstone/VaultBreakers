# Asset and dependency license register

Recorded: 2026-09-09. This register identifies the current sources and licensing
exceptions; it does not relicense third-party materials under the root proprietary
license. Preserve each dependency's license and applicable third-party notices when
redistributing it. Review the actual distribution contents before release.

## Project-authored materials

| Material | Source/provenance | Terms |
|---|---|---|
| Gameplay and editor code, design documents | Source files in this repository | Root `LICENSE`, except identified third-party content |
| Modular character, equipment, Blender source and FBX | `Tools/Blender/dungeon_assets.py`, with the shared `stylized_assets.py` animation/export helpers; canonical source documented in `Docs/MODULAR_AVATAR_PIPELINE.md` | Root `LICENSE` |
| Dock 9 scenery, enemy, arena, training, platform and projectile meshes | `Tools/Blender/dungeon_assets.py` and `generate_arena_assets.py`; editable sources under `ArtSource/Blender/` | Root `LICENSE` |
| Validation animation clips | `Tools/Blender/stylized_assets.py`; dedicated animation FBX | Root `LICENSE` |
| Arena collision primitives, materials and presentation geometry | `Assets/Vaultbreakers/Editor/` setup tooling and runtime presentation code | Root `LICENSE` |
| Placeholder combat audio | Generated by `Assets/Vaultbreakers/Scripts/Combat/PlaceholderAudio.cs` | Root `LICENSE` |
| Avatar preview images | Blender generator and `VaultbreakersPreviewCapture.cs` | Root `LICENSE` |

No externally sourced character, animation, texture, or audio collection was identified
in the current project assets. Add its creator, source URL, version, license, proof of
purchase/permission where required, and usage restrictions here before importing one.
Future production audio and animation are not covered by the generated placeholders.

## Unity and package dependencies

Unity terms. Package versions are pinned by `Packages/manifest.json` and the resolved
`Packages/packages-lock.json`. Package Manager restores their own license files; the
local `Library/PackageCache` is generated and is not committed. A package license does
not grant a license to the original Vaultbreakers code or assets.
